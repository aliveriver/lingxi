# X2 Ultra腕部连通分块与安装约束

2026-09-29，接续[直装接口与模型几何续查](x2-ultra-o10-mount-geometry.md)，只读分析已保存的官方STL。**可以定位模型中的候选接触面，但现有证据仍不能唯一确定本机腕掌变换，也不能拆分原腕部聚合惯性。** 本轮把这两个缺口量化，并增加可测试的离线工具；没有猜测装配参数或继续加大补偿。

用户已确认O10掌根直接固定在手腕上。该机械关系保持有效；本轮没有连接PC1/PC2、重新采集现场信息、执行动作或部署。

## 腕部网格能分成三个连通部分

按**完全相同的顶点坐标**连通分组，左右各3组。再分别把坐标四舍五入到10nm、100nm、1μm后分组，三组的三角形数量保持不变。此检查说明当前分块不是一个任意切割平面造成的，但不证明一个连通部分就是一个可拆卸实物零件；接触的多个CAD实体也可能被连成一组。

| 分组 | 左三角形数 | 右三角形数 | 左侧Z范围 mm | 目视形状 |
| --- | ---: | ---: | ---: | --- |
| C0 | 24,438 | 22,062 | −181.702至−41.500 | 固定手及其根部外形 |
| C1 | 8,814 | 9,002 | −50.500至+16.500 | 腕部主要支架形状 |
| C2 | 4,950 | 4,950 | −38.000至+9.933 | 腕部另一侧支架形状 |

右侧C0的最低Z为−181.722mm，另外两组Z范围与左侧相同。分组号仅按三角形数排序，不是厂家的物料编号。

![腕部网格连通分组](../logs/wrist-components-20260929/wrist-components-final.png)

图中颜色只区分网格连通性，红色十字是 `wrist_roll_link` 原点。没有移除原模型中的部件、加入O10或生成装配模型。

## 平面位置已提取，实际配合面还没有确认

本工具按三角形三个顶点Z跨度≤10nm筛选与XY平行的面，再以0.1μm的Z分箱汇总面积。这是文件分析容差，**不是模型或实物精度声明**。面积是三角形面积之和，未做重叠面的几何并集，也不是已测接触面积。

左右C0和C1都存在 `z=−41.5mm` 的平面三角形；C1还存在 `z=−36mm、−39.5mm、−50.5mm` 等面。左C0在−41.5mm处的三角形面积和约1264.39mm²，C1约315.17mm²。它们是旧固定手和腕部几何关系的线索，不足以认定O10应安装在其中哪一个面。

独立O10掌根在底部附近也存在 `z=0、0.05、1.55、7.25、8.45、10.85mm` 等平面。产品说明书又明确安装时拆去手腕后端盖。因此不能把掌根网格的最小Z、最大面积平面或任意壳体平面自动当成安装基准；需把图纸/CAD中的实际配合面对应到URDF坐标。

若将掌根中的平面 `n_pᵀp_p=d_p` 映射到腕系平面 `n_wᵀp_w=d_w`，其中 `p_w=R p_p+t`，在统一法向符号后，平面重合只提供：

```text
R n_p = n_w
n_wᵀ t = d_w − d_p
```

这约束法向和法向位移，仍留下平面内的两个平移量以及绕法向的转角。实际相向接触的两个外法向符号还需确认。需要有对应的孔中心、非对称定位特征/走线方向或明确装配坐标，才能消除剩余自由度。**本轮没有选定配合面，所以连完整的数值候选变换也未输出。** 没有搬用v1.4的安装joint来填这些空白。

## 网格分块不能代替惯性分账

原v1.3每侧腕roll仅有一组质量、COM及惯性张量。即使确认C0是应替换的形状，也无法由这一组聚合参数唯一求出C0/C1/C2各自的质量、COM和张量。将几何体积分乘以假定统一密度，或按视觉体积比例分摊0.303kg，都会引入未证实的材料/空腔假设，本轮没有这样计算。

此外，按精确STL顶点检查边关联得到：

| 网格 | 单面边数 | 超过两面共享的边数 |
| --- | ---: | ---: |
| 左C0 | 64 | 16 |
| 左C1 | 92 | 0 |
| 左C2 | 36 | 0 |
| 右C0 | 0 | 14 |
| 右C1 | 0 | 0 |
| 右C2 | 36 | 0 |

这些是未焊接/修复的渲染网格的拓扑计数；浮点缝隙可影响单面边数，不据此判定实物缺陷。即使某组每条边恰有两面，也仍需检查自交、内部壳层、材质等，不能因此把它当成可靠质量模型。脚本不导出体积质量，也不修补原网格。

## 下一步的具体输入

现有手侧说明书、STEP和旧机器人网格已能支持后续装配核对；继续仅靠这些文件拟合，不能把未知参数变成已确认参数。下一步需要的最小新增资料是：

1. 本机保留腕部的装配图或CAD，能把实际安装面、孔中心和定位方向关联到左右 `wrist_roll_link`；也可直接提供对应型号的完整v1.3+O10模型。
2. 保留腕部和拆除旧末端的质量、COM、惯性分账；部件CAD须带适用材料/质量属性或厂家给出的参数。

取得后才能求左右固定变换并核对质量，HAL手坐标映射及被动轴版本仍需独立核实。远程期间不通过实机试跑来猜外参，不替换当前诊断模型。
