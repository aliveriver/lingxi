# 前端

启动：

```bash
uv run x2 --config config/x2.yaml web --host 0.0.0.0 --port 8080
```

界面包含连接/能力状态、RGB-D 压缩画面、14 个手臂关节、双手 10 轴状态、目标滑条和日志。移动端会折叠为单列操作面。

HTTP API：

| 方法 | 路径 | 功能 |
| --- | --- | --- |
| GET | `/api/status` | 后端、固件、能力与警告 |
| GET | `/api/state` | 双臂/双手/可用触觉状态 |
| GET | `/api/cameras/{camera}/frame` | 最新压缩帧 |
| POST | `/api/control/arm` | 14 轴时间插值目标 |
| POST | `/api/control/hand` | 单手 10 轴时间插值目标 |

控制请求必须携带精确确认短语，服务端仍执行配置、控制权、反馈和竞争发布者互锁。前端不是安全 PLC 或急停装置。

默认 `127.0.0.1` 监听。使用 `0.0.0.0` 会暴露在机器人网络；当前没有账户认证，务必只在隔离实验网络使用，不要公网转发。
