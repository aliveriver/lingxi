# 左肩有界重力位置偏置诊断：已执行范围与下一轮候选

## 首次实际执行：bias-only，已完成

原方案缩减为原始基线1s → 偏置渐入2s → 保持1s → 偏置渐出2s → 恢复1s，名义50Hz、350帧。期望位置始终0.400rad，发送0.400→0.402→0.400rad，**没有执行下文650帧计划中的+0.01rad期望运动**。详细证据见 [首次报告](../gravity-live-first-trial.md)。

实际350帧、43.123Hz、最大间隔44.018ms，HAL目标正确；编码器增量与撤偏置后的残余均为+0.000191689rad。结论为 `bias_only_diagnostic_complete`，尚无补偿有效改善位置跟随的证据，位置验收仍未通过。没有继续加偏置或重复试验。本轮离线收尾不连接机器人，下文均不构成新动作授权。

## 保留供审查的原候选与保护

历史授权范围：用户在首次试验前明确要求启用重力补偿，并确认稳定站立、活动区清空、现场可急停。该确认已随本次试验完成而结束，不能用于新试验。只通过现有 MC/URS 位置接口，在稳定站立时执行一次左肩 pitch 诊断，不修改 MC/增益，不直发 HAL，不注入力矩。

本机模型/IMU安装方向/手部惯性尚未完全核实。因此不是直接选一组外参并发送完整tau/K：计算胸部与胯部两路传感器、单位旋转/出厂矩阵/转置共六种假设，只有每一种在当前期望姿态都支持相同的 **+0.002rad 限幅结果** 时才允许这一步。此一致性不是校准证明，也不排除所有未建模负载/传动误差。

固定已审计PC2 SDK URDF和出厂校准文件哈希，K假定40；按文件原有末端惯性计算，不额外加入未知手质量。原始估计、每个候选的重力向量/力矩/未限幅偏置、截断量均记录。补偿仅左肩，其余13轴全程使用经验证的HAL命令基线，手部固定在流开始时的测量目标。

原候选轨迹（650帧，未执行）：原始基线驻留1s → 补偿渐入2s → 带补偿基线驻留1s → 期望+0.01rad五次移动2s → 目标驻留1s → 返回带补偿基线2s → 驻留1s → 补偿渐出2s → 原始基线驻留1s。名义50Hz、650帧，最终与初始命令一致。额外偏置≤0.002rad、偏置变化率≤0.002rad/s、总命令偏移≤0.012rad、命令变化率≤0.012rad/s，限位取模型与项目交集。

每帧保护：两路IMU、腰、臂源时间和接收时间≤100ms，流间差≤50ms；IMU加速度模长9–10.5m/s²且与四元数重力方向差≤3°；各假设躯干倾角≤10°、彼此方向差≤5°、相对首次资格检查变化≤1°。解析异常、故障、不完整关节、限位或假设不一致均拒绝。发布前再次检查数据年龄，间隔>50ms拒绝；左肩编码器相对试验前偏移>0.025rad或其他轴>0.005rad拒绝。继续复用MC模式/站立/故障/图竞争与订阅保护。

`--dry-run` 对真实传感器执行所选计划的计算（原候选650帧；加 `--bias-only` 为350帧），但不切换模式、不打开命令流、不创建命令发布者；单独记录shadow计时，物理发布数必须为0。shadow 通过且取得本次现场确认后才可运行同一计划的 `--confirm-hardware`，磁盘control保持false，仅进程内暂时开启。进入模式失败或执行异常均尝试恢复STAND_DEFAULT，并关闭进程内控制。正常结束用五次曲线撤销偏置；反馈/服务故障、进程强杀或断电不保证机械回位，现场急停条件仍必要。

分析分别报告：相对带补偿基线的期望+0.01rad跟随、返回带补偿基线残余、完全撤销偏置后相对原始基线残余、原始期望位置绝对误差。所有窗口取相应URS驻留末尾0.2秒；不得拿切回站立后的位置替换。首次是有界部分补偿试验，饱和到0.002rad不代表完整重力抵消；若失败停止，不自动加偏置或位移。


## 下一轮最小判别方案（尚未执行）

目的：区分“附加偏置可传到HAL”与“偏置能改善期望运动及回位”。重复现有bias-only试验仅能检查该微小响应是否重现，无法回答+0.01rad跟随是否改善；不为补日志重复第一次试验，也不因响应小就自动提高偏置/增益。

1. 先完成离线部署校验，并梳理模型/标定适配问题供现场或厂商核查：HAL是否已应用零位标定、IMU安装矩阵方向、腕部惯性是否含手。当前只知道这些仍不确定，不能把缺少重力补偿当作唯一根因。
2. 若决定测试补偿对跟随的作用，候选仍为左肩索引0、期望增量+0.01rad、偏置上限+0.002rad、原650帧分段。其他轴固定HAL基线，双手固定；不加幅、不改增益。每次都需新的现场确认和新鲜的只读资格检查，再执行该计划的shadow。
3. 为判定补偿效果，先离线准备**相同分段/驻留/五次曲线时长**的无补偿对照，只把偏置改为零；两组原始HAL基线必须一致。现有350帧无补偿记录用于历史参照，不足以替代650帧的匹配对照。现已实现并离线验证专用脚本必填 `--compensation on|off`，两组均保留650帧，见 [匹配对照](../gravity-comparison.md)；尚未部署或实机执行，不能用改日志或逐段编码器基线拼出对照。最小比较为各一条；不预授权自动连续执行，两次之间先分析并重新确认现场。
4. 同步比较上层命令、HAL目标及编码器，分别报告：目标驻留相对带偏置基线的增量误差、相对原始期望的绝对误差、返回带偏置基线的残余、完全撤偏置后的原始基线残余、其他轴漂移。窗口仍为各URS驻留末尾0.2s。单阶梯差异不能据以判断改善，不以reported effort、声音或站立后读数替代。
5. 工程阈值保持：期望增量跟随误差≤0.002rad、原始期望绝对误差≤0.005rad、两种回位残余分别≤0.001rad、其他轴漂移≤0.005rad、驻留窗口波动≤0.002rad。证据质量或保护失败则该轮停止，运动指标失败也不自动重试/加幅；先分析原因再决定新方案。只有单次位置验收通过后才规划至少三次同条件合格记录的重复性验收，之后依次多轴、手接触/压力、实机模型闭环。

“误差有所下降”和“验收通过”应分别报告。一般固定基线验收器的重复性结果不能直接用于不同补偿配置；需按期望幅度、HAL基线、补偿开关/上限、模型/标定哈希、轨迹分段和增益一致性单独分组。匹配对照及离线比较器已实现，尚待PC2校验部署与现场逐次确认，本轮没有执行。
