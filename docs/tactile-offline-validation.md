# 压力显示与录放的离线补强（2026-09-29）

本轮修复压力显示中“缺侧消失”和“请求挂起时旧图仍显示新鲜”的问题，并补齐原始字节、网格完整性与录放一致性的检查。**全部接触图案均为合成软件测试数据，灵巧手实际接触/压力响应仍未验收。** 没有连接PC1/PC2、执行动作或部署，没有修改HAL手符号、坐标映射、MC或补偿参数。

## 页面现在如何区分数据状态

左右手始终各有状态区域，单侧缺失显示“缺少数据”，不补零，也不沿用上一帧的图。收到有效全零帧则仍显示完整网格与“非零0/141”；这是不同状态。

实时页每250ms更新页面估计接收龄，即使下次HTTP请求挂起也继续老化；超过0.5秒时旧网格灰显并明确标为旧值。读取失败会清除原网格，留下两侧缺失占位。0.5秒沿用原页面的新鲜度提示标准，是显示准则，不是厂家传感器硬时限或控制互锁。页面估计龄以服务端接收龄加浏览器收到响应后的时间计算，不包含未知的传输延迟；后台标签页计时器可能被浏览器节流，不能用于安全停机。

回放页始终使用**原始采集时刻减原始接收时刻**，不随当前墙钟或翻页等待而改变。实时与历史视图分开。时间来自未来的实时帧标为时间异常，不自动随等待变成有效；严格JSONL读取仍拒绝传感器接收时刻晚于采集的记录。

网格保留固定0–255色标、原始整数及数组顺序。255计为“达字节上限”，不称为已确认的物理压力饱和。source为`mock/`或`synthetic/`时页面和PNG明确标注合成来源；没有压力单位或朝向标定。

## 原始数据校验与录放

新增[tactile_quality.py](../src/lingxi_x2/tactile_quality.py)，供实时API、历史回放API及录制检查共同使用：每侧掌面5×5、手背6×6、thumb/index/middle/ring/little各4×4，严格核对名称、形状、侧别、单位、时间戳和全部原始整数。每侧应有141格。

JSONL读取在Pydantic转换之前检查原始压力类型，拒绝布尔值、字符串、浮点数、越界值、缺少指尖及伪装成相同格数的错误形状，避免隐式类型转换掩盖坏数据。缺整侧可保留为缺失；存在但不完整的帧是错误。不会裁剪到0–255、补齐缺格或跳过坏行。历史错误文件保留，若需修复须另存。

`inspect-recording`新增每侧fresh/stale/missing数量、达到255的格点样本数及重复接收时间戳数量。缺失也可能是主动未录制触觉，重复时间戳也可能是读取缓存；**它们不是HAL丢包数或传感器故障诊断**。全零和非零值仍不能证明真实接触有效。

PNG导出继续保存完整原始JSON，增加合成来源、字节上限计数及未验收标志。现在PNG或同名JSON任一个已存在都会拒绝，不覆盖旧证据；缺整侧或网格不完整也不会生成伪完整图。实时新鲜度仍由采集后端负责，导出函数没有推断当前现场状态。

```bash
  --output /tmp/new-synthetic-tactile.jsonl

```
